# 한국 메모리 수출 관측값

조사일: 2026-09-12. 무료 관세청 API 수집기: `fetch_memory_exports.py`.

## 연결 상태

공공데이터포털의 **관세청_품목별 수출입실적(GW)** 공식 API를 사용한다.
무료이지만 활용신청으로 받은 서비스키가 필요하다. 현재 실행 환경에서
`KCS_API_KEY` 또는 `DATA_GO_KR_API_KEY` 설정은 확인되지 않았다.
그래서 초기 JSON은 실제 값 없이 `needs_api_key` 상태이며 임의 수출량을 넣지 않는다.
TRASS 유료회원 로그인은 별도 서비스인 이 API의 인증키를 대신하지 않는다.

서비스키는 서버/CI 환경변수에만 설정한다. 브라우저 코드, 공개 JSON, 로그에 기록하지 않는다.
데이터 사용권은 공공데이터포털에서 무료·이용허락범위 제한 없음으로 안내된다.

- 공식 데이터 안내·요청 규격: <https://www.data.go.kr/data/15101609/openapi.do>
- 공식 메타데이터: <https://www.data.go.kr/catalog/15101609/openapi.json>
- API: `https://apis.data.go.kr/1220000/Itemtrade/getItemtradeList`
- 필수 파라미터: `serviceKey`, `strtYymm`, `endYymm`; 품목 지정: `hsSgn`
- 공식 Swagger 응답 항목: `year`, `hsCode`, `expDlr`(달러), `expWgt`(KG), `statKor` 등.
- 수출은 FOB 신고미화금액, 중량은 **순중량 kg**. 수입 CIF와 섞지 않는다.

## 품목 범위

| 코드 | 2026년 관세율표 공식 명칭 | 화면에서 가능한 해석 |
|---|---|---|
| 8542321010 | 디램 / DRAM | 모노리식 DRAM 집적회로 수출; HBM 및 DRAM 모듈 전체 출하 아님 |
| 8542321030 | 플래시 메모리 / Flash memory | 플래시 메모리 수출; NAND 전용 수출이라고 부르면 안 됨 |

공식 2026년 분류: <https://unipass.customs.go.kr/clip/hsinfosrch/openULS0201005Q.do?searchVal=854232>

이 두 코드는 과거 한·베트남 FTA 양허표에도 같은 품명으로 존재한다:
<https://customs.go.kr/download/ftaportalkor/_down/trty/han_vn_05_eng.pdf>.
이는 코드의 과거 존재 확인이며 매년 개정표의 전체 연혁을 대조했다는 뜻은 아니다.
과거 연도 응답에서도 요청 HS10와 일치하는 행만 수록하고, 다른 품목으로 대체하지 않는다.
2026년 표의 8542323000(복합구조칩)과 8542324000(MCO)은 별도 범주다.
따라서 854232 전체를 DRAM/HBM이라고 합산하거나 Flash를 순수 NAND라고 단정하지 않는다.

## 발표 일정과 빠른 갱신

관세청 API 안내가 보장하는 범위는 **매월 15일경 전월까지 자료 현행화**다.
신고 정정·취하가 반영되므로 이미 저장한 과거 월도 수정될 수 있다.
정확한 고정 발표 시각, 해당 API 서버에 반영되는 지연 시간은 공식 문서에 없다.

운영 정책은 원출처 발표 일정과 별개로 저장한다. 제안된 수집 실행 창은
매월 15~18일 5분 간격, 나머지 날 하루 1회다. 이는 공식 발표 시각이 아니며,
워크플로/상주 실행기의 실제 실행 간격과 지연에 따라 감지 속도가 달라진다.
수집기가 자체 예약 작업을 생성하지는 않는다. 부모 워크플로에서 호출한다.
원출처 업데이트 시각이 제공되지 않으면 `source_updated_at=null`을 유지한다.
`checked_at`은 우리 서버의 확인 시각이고 `first_seen_at`은 처음 발견한 시각이다.
관측월, 공식 발표시각, 우리 확인 시각을 서로 바꿔 표시하지 않는다.

관세청 잠정 수출입 발표는 1일·11일·21일을 확인할 수 있지만 **위 HS10 API의
발표 일정이나 DRAM/NAND 물량 데이터라는 뜻은 아니다**. 예를 들어 2026-09-11
관세청 보도자료는 9월 1~10일 총괄·주요품목 잠정치다:
<https://customs.go.kr/kcs/na/ntt/selectNttInfo.do?bbsId=1362&mi=2891&nttSn=10176444&nttSnUrl=8599e04facbad02816d3af783a538778>.
공식 주요품목 분류는 관세청 성질별 분류이며 메모리 HS10와 동일하지 않다.

## 수집·수정 보존

`python fetch_memory_exports.py`는 기본적으로 최근 60개월을 요청해 과거 수정도 반영한다.
`--start YYYYMM --end YYYYMM` 또는 `--history-months N`으로 초기 이력을 바꿀 수 있다.
최초 수집 후 빠른 확인 창에서는 `--recent-only`로 최근 완료된 한 달·두 품목만 요청한다.
하루 한 번 전체 60개월을 다시 조회하면 정정도 반영할 수 있다.
`--only-if-changed`는 값·상태·정책 변화 없이 조회 시각만 바뀌면 JSON을 그대로 둔다.
이때 JSON 확인시각은 마지막 저장 시점이며 매 실행의 확인 여부는 워크플로 로그로 확인한다.
공식 허용 범위를 지키기 위해 연도별로 요청을 나눠 수집한다.
서비스키가 없거나 응답 실패 시 기존 관측값을 지우지 않고 상태를 명시한다.
숫자 누락은 0으로 치환하지 않는다. 수집한 0은 실제 0으로 보존한다.
같은 월의 값이 달라지면 `revised_at`을 기록한다.

## 투자 지표로 읽는 법

수출금액은 제품 가격, 제품 구성, 출하량의 영향을 함께 받는다. 순중량은 칩 개수나
비트 출하량이 아니며 고부가 제품과 패키지 구성이 바뀌면 금액/중량도 달라진다.
따라서 현물·계약 가격 및 기업 실적과 나란히 보되, 한국 전체 수출 변화가 삼성전자나
SK하이닉스 한 회사의 매출 변화와 같다고 해석하지 않는다.
